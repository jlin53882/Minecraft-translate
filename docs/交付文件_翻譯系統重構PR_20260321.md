## A-1：修復 `dry_run` 和 `export_cache_only` 完全失效 [Critical]

**檔案**：`translation_tool/core/lm_translator_main.py`

**問題**：`translate_batch_smart()` 的 `dry_run` 和 `export_cache_only` 參數傳到 `_execute_translation()` 後沒有傳遞到實際執行的 `translate_batch_smart_old()`。

**修復方向**：
在 `_execute_translation()` 進入 `while remaining` 迴圈前，先檢查：

```python
def _execute_translation(items, batch_size, batch_profile, total,
                         dry_run=False, export_cache_only=False):
    if dry_run:
        # 只輸出：有哪些 items、估計 API 消耗、不實際呼叫
        return {"dry_run": True, "items": items, "estimated_calls": len(items) // batch_size}
    if export_cache_only:
        # 只查快取，不呼叫 API
        return translate_batch_smart_old(items, total, use_cache_only=True)
    return translate_batch_smart_old(items, total)
```

**驗證方式**：
```bash
pytest tests/test_lm_translator_main.py -k "dry_run or export_cache"
```

## A-6：動態化 RPM 等待時間 [Medium]

**檔案**：`translation_tool/core/lm_translator_main.py`

**問題**：
- 目前固定等待 12 秒（浪費）
- 邏輯是「最後一個 batch 才等一口氣 12 秒」，但 RPM 限制是「每批次都該控制節奏」

**修復方向**：

```python
# config.json 新增
{
  "lm_translator": {
    "rpm_limit": 15,              // 每分鐘上限（預設）
    "request_interval": 4,         // 主動控制的間隔（秒）
    "use_api_retry_delay": true    // 429時優先用API Retry-After
  }
}

def _calculate_wait_time(retry_info: RetryInfo | None, lm_config: dict) -> float:
    if retry_info and lm_config.get("use_api_retry_delay"):
        return retry_info.retry_delay  # 優先用 API 告知的時間
    return lm_config.get("request_interval", 4.0)  # 用設定的主動間隔

# 每批次完成後都控制間隔（不再只最後才等）
def _maybe_wait_for_rpm(last_request_time: float, lm_config: dict) -> float:
    interval = lm_config.get("request_interval", 4.0)
    elapsed = time.time() - last_request_time
    if elapsed < interval:
        return interval - elapsed
    return 0.0
```

## B-1：改善 JSON 截斷偵測 [Medium]

**檔案**：`translation_tool/core/lm_translator_main.py`

**問題**：目前只檢查結尾是否是 `}` 或 `]`，會誤判。

**修復方向**：
```python
import json

def is_truly_truncated(raw_text: str) -> bool:
    try:
        json.loads(raw_text)
        return False  # 成功，代表沒截斷
    except json.JSONDecodeError:
        pass
    # 大括號平衡檢查
    count = 0
    for ch in raw_text:
        if ch == '{': count += 1
        elif ch == '}': count -= 1
        if count < 0:
            return True  # } 比 { 先出現，代表截斷
    return count != 0
```

**修復方向**：

def validate_translation_item(original: str, translated: str) -> tuple[bool, str]:
    if not translated or translated.strip() == "":
        return False, "empty"
    if original.strip() == translated.strip():
        return False, "lazy"  # 原文含英文，翻譯後完全相同

def save_checkpoint(processed_index: int, remaining_items: list):
    with open(CHECKPOINT_FILE, "w") as f:
        json.dump({"index": processed_index, "remaining": remaining_items}, f)

def load_checkpoint() -> tuple[int, list] | None:
    if not os.path.exists(CHECKPOINT_FILE):
        return None
    with open(CHECKPOINT_FILE) as f:
        data = json.load(f)
    return data["index"], data["remaining"]

## C-1：移除 BOM 檔案（Critical）[Critical]

**檔案**：`app\ui\components.py`、`app\ui\quick_jump.py`

**問題**：這兩個檔案以 BOM（U+FEFF）開頭，Python 無法正常解析。

**修復**：
```bash
# 在專案目錄下執行
Get-ChildItem -Path . -Filter "*.py" -Recurse | ForEach-Object {
    $bytes = [System.IO.File]::ReadAllBytes($_.FullName)
    if ($bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF) {
        [System.IO.File]::WriteAllBytes($_.FullName, $bytes[3..($bytes.Length-1)])
        Write-Host "Removed BOM: $($_.FullName)"
    }
}
```

**驗證**：
```bash
python -m py_compile app/ui/components.py
python -m py_compile app/ui/quick_jump.py
```

## C-2：`config_manager` 加入基本 schema 驗證 [High]

**檔案**：`translation_tool/utils/config_manager.py`

**問題**：無 schema 驗證，錯誤格式導致翻譯中途 crash。

**修復方向**：
```python
# 簡單的型別驗證（不需要引入 pydantic）
_REQUIRED_LM_KEYS = {
    "keys": list,
    "model": str,
    "initial_batch_size_lang": (int, type(None)),
    "initial_batch_size_patchouli": (int, type(None)),
    "rpm_limit": (int, type(None)),
    "request_interval": (int, float, type(None)),
}

def validate_config(config: dict) -> list[str]:
    errors = []
    for key, expected_type in _REQUIRED_LM_KEYS.items():
        if key not in config:
            continue  # 可選欄位
        if not isinstance(config[key], expected_type):
            errors.append(f"lm_translator.{key} 應為 {expected_type}，實際為 {type(config[key])}")
    return errors
```
