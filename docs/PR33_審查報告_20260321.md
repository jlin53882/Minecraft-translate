## 🔴 Critical — 阻擋 Merge

### ATK-004/017（實為新引入）| `_safe_add_log` / `_safe_page_update` 遞迴崩潰

**檔案**：`app/views/translation/translation_actions.py`

```python
# ❌ 錯誤實作（PR #33 現況）
def _safe_add_log(view, message: str):
    try:
        if hasattr(view, "session") and view.session is not None:
            _safe_add_log(view, message)   # ← 呼叫自己！不是 view.session.add_log()
    except Exception:
        pass

def _safe_page_update(view):
    try:
        if hasattr(view, "page") and view.page is not None:
            _safe_page_update(view)         # ← 呼叫自己！不是 view.page.update()
    except Exception:
        pass
```

**問題**：
- 這兩個函式在檢查 `view.session` / `view.page` 存在後，應該呼叫 `view.session.add_log(message)` 與 `view.page.update()`
- 卻錯誤地呼叫了**自己**，造成無窮遞迴
- 第一次 worker thread 嘗試寫 log 時，程式就會觸發 `RecursionError: maximum recursion depth exceeded` 並崩潰

**正確實作**：
```python
def _safe_add_log(view, message: str):
    try:
        if hasattr(view, "session") and view.session is not None:
            view.session.add_log(message)   # 呼叫實際方法
    except Exception:
        pass

def _safe_page_update(view):
    try:
        if view.page is not None:
            view.page.update()
    except Exception:
        pass
```

**修復方向**：一行修正：`view.session.add_log(message)` 替換 `_safe_add_log(view, message)`，`view.page.update()` 替換 `_safe_page_update(view)`。

**審查結果**：❌ **引入新 Critical bug** — PR 說是「ATK-004/017 修復」，實際上在第一次 worker log 寫入時崩潰，完全無法使用。

### iniital→initial 拼寫修復 | 向後相容破壞

| 位置 | 狀態 |
|------|------|
| 程式碼（`lm_translator.py` 等） | ✅ 已修正 |

**風險**：使用者的 `config.json` 寫 `iniital_batch_size_lang: 200`，`load_config()` 找不到 key 就用 fallback（`lang_merger.py: 300`），靜默失效無任何警告。

**修復方向**：
```python
# config_manager.py 中新增
def _check_deprecated_keys(config: dict):
    deprecated = [k for k in config if k.startswith("iniital")]
    if deprecated:
        log_warning(f"已棄用的設定 key：{deprecated}，請改用 initial_*")
```
