# Merge UI 排版優化建議（實作前筆記）

## 目標
- 降低閱讀壓力
- 移除重複語意
- 把設定分成明確區塊
- 避免一行內塞太多 label + switch + 說明

## 建議方向

### 1. 輸出與選項卡片拆成三段
1. 輸出資料夾
2. 一般選項
3. Patchouli 進階

### 2. `zh_cn` 區塊
- 不要同時出現「zh_cn 處理」+「處理 zh_cn 檔案」兩個近似標題
- 改成：
  - 區塊標題：`簡體中文（zh_cn）處理`
  - switch label：`啟用 zh_cn 檔案處理`

### 3. Patchouli 區塊
- 每個設定改成垂直卡片列，不要用左 label + 右 switch 的擁擠形式
- 結構：
  - 設定標題
  - switch / 輸入框
  - 1 行說明

### 4. threshold
- 不要再用「Patchouli 有效翻譯比例門檻」+「翻譯有效性門檻：」雙重命名
- 改成單一標題 + TextField

### 5. disabled note
- 放在相關控制項下方
- 樣式用紅色小字即可

## 預期結果
- 視覺上更像設定頁，而不是 debug 表單
- 使用者可快速理解：
  - 哪些是一般選項
  - 哪些是 zh_cn 控制
  - 哪些是 Patchouli 進階設定
