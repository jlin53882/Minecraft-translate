# Rules View 搜尋優化 PR

> 日期：2026-03-16

## 問題
1. 搜尋結果只用顏色標記，切換頁面後找不到符合內容
2. 只能搜尋 `from` 和 `to` 欄位
3. 無法快速導航到上一筆/下一筆

## 優化內容

### 1. 搜尋結果過濾（取代標記顏色）
- 搜尋後只顯示符合的資料，不是標記顏色
- 顯示「找到 X 筆」數量
- 強制顯示第一頁

### 2. 多欄位搜尋
- `from`：來源文字
- `to`：目標文字
- `comment`：備註
- `category`：分類

### 3. Regex 模式
- 輸入 `/pattern/` 使用正則表達式
- 忽略開頭結尾的 `/`

### 4. 大小寫切換
- 預設不區分大小寫
- 可切換為區分大小寫

### 5. 結果導航
- 「上一筆」「下一筆」按鈕
- 快速跳轉到符合的項目

### 6. Debounce
- 停止輸入 300ms 後才搜尋
