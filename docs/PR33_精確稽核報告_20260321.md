## 🔴 Critical — 阻擋 Merge

### Bug M-1 | `_safe_add_log` / `_safe_page_update` 遞迴呼叫自己

**檔案**：`app/views/translation/translation_actions.py`

#### 錯誤程式碼（本 PR 引入）

```python
# 第 17-23 行
def _safe_add_log(view, message: str):
    """執行緒安全地寫入 session log。view 已卸載時靜靜忽略。"""
    try:
        if hasattr(view, "session") and view.session is not None:
            _safe_add_log(view, message)   # ← 第 21 行：呼叫自己！不是 view.session.add_log()
    except Exception:
        pass  # view 已卸載或 session 已 GC，忽略

# 第 26-32 行
def _safe_page_update(view):
    """執行緒安全地更新 page。view 已卸載時靜靜忽略。"""
    try:
        if hasattr(view, "page") and view.page is not None:
            _safe_page_update(view)        # ← 第 30 行：呼叫自己！不是 view.page.update()
    except Exception:
        pass  # view 已卸載，忽略
```

#### 遞迴呼叫棧追蹤

```
_safe_add_log(view, "[UI] 服務執行失敗：...")
  └→ if hasattr(view, "session") and view.session is not None:  ✓ True（session 存在）
      └→ _safe_add_log(view, "[UI] 服務執行失敗：...")          ← 呼叫自己
          └→ if hasattr(view, "session") ...                   ✓ True
              └→ _safe_add_log(view, ...)                       ← 再次呼叫自己
                  └→ ...（無限遞迴）
                  └→ RecursionError: maximum recursion depth exceeded
```

#### 觸發呼叫點（共 7 處，全部會崩潰）

| 函式 | 行號 | 呼叫內容 | 情境 |
|------|------|----------|------|
| `run_ftb()` | 54 | `_safe_page_update(view)` | 翻譯初始化時 |
| `run_ftb()` worker exception | 78 | `_safe_add_log(view, msg)` | 翻譯中途錯誤時 |
| `run_kjs()` | 107 | `_safe_page_update(view)` | 翻譯初始化時 |
| `run_kjs()` worker exception | 130 | `_safe_add_log(view, msg)` | 翻譯中途錯誤時 |
| `run_md()` | 159 | `_safe_page_update(view)` | 翻譯初始化時 |
| `run_md()` worker exception | 183 | `_safe_add_log(view, msg)` | 翻譯中途錯誤時 |
| `start_ui_timer()` loop | 237 | `_safe_page_update(view)` | 翻譯完成狀態更新時 |

#### 正確實作

```python
def _safe_add_log(view, message: str):
    """執行緒安全地寫入 session log。view 已卸載時靜靜忽略。"""
    try:
        if hasattr(view, "session") and view.session is not None:
            view.session.add_log(message)   # ← 呼叫實際方法，不是自己
    except Exception:
        pass

def _safe_page_update(view):
    """執行緒安全地更新 page。view 已卸載時靜靜忽略。"""
    try:
        if view.page is not None:
            view.page.update()             # ← 呼叫實際方法，不是自己
    except Exception:
        pass
```

#### PR 內部不一致（次要問題）

在 worker exception handler 中（78、130、183 行）：

```python
if hasattr(view.session, "add_log"):
    _safe_add_log(view, f"[UI] 服務執行失敗：{ex}")   # ← 包了一層但有 bug
if hasattr(view.session, "set_error"):
    view.session.set_error(str(ex))                     # ← 這個卻直接呼叫
```

`set_error` 採用直接呼叫（正確），`add_log` 卻包了一層有 bug 的 `_safe_add_log`。這個不一致證實這是 copy-paste + typo 引入的失誤，而非有意識的設計。

#### 修復對照

| 位置 | 現況（錯誤） | 應改為 |
|------|-------------|--------|
| 第 21 行 | `_safe_add_log(view, message)` | `view.session.add_log(message)` |
| 第 30 行 | `_safe_page_update(view)` | `view.page.update()` |
